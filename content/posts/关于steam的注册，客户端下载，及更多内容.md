# 准备工作：
1. 一个邮箱（事实上不太推荐QQ邮箱，不过我自己用的就是QQ邮箱，所以无所diao谓）、
2. 一台电脑（win10/11，mac也行，Linux......也不是不可以，但是我这里不教macOS和Linux的安装方法）（电脑下载电脑客户端用，你要是不玩游戏只是领个别人送的礼物，或者趁促销结束前赶紧买个游戏，那一台手机也可以）
3. 加速器
	- UU加速器、雷神加速器、迅游加速器皆可免费加速steam，可以使用
	- 使用VPN的朋友，可以直接使用VPN
	- steam++（watt tolkit）也可免费加速
# 安装steam Windows客户端（以下简称客户端）
1. 开启加速器
2. 打开[steam官网](https://store.steampowered.com)
3. 点击右上方的绿色按钮「安装steam」
4. 点击左侧蓝色大按钮「安装steam」，然后运行浏览器所下载的可执行文件（.exe）
5. 双击安装包，若弹出用户账户控制界面，选择是，进入安装页面
6. 一路选择下一步
	注：在选定安装路径时，遵循一下要点：
	- 路径内无中文字符，包括特殊符号
	- 建议不要装到C盘（当然只有C盘那就装C盘吧）
7. 完成，steam自动更新，等待即可
# 注册
	注：此步骤极难（），可寻求他人帮助
1. 在客户端窗口打开后，点击登录界面的右下角「创建免费账户」
2. 填写你的邮箱到上面两行
3. 进行人机验证
	注：此步骤极难（）建议使用手机热点作为WiFi，并保持加速器开启。若失败请多次尝试，或更换加速器节点
4. 勾选同意条款
5. 在出现「正在等待您进行验证」的窗口后，打开邮箱，接收到一封来自steam的邮件，点击邮件中的蓝色大按钮「验证我的电子邮件地址」
6. 想一个好记的名称，用于账户登录，只可使用英文、数字，不可使用中文与特殊字符
7. 想一个好记的密码，用于登录
# 登录
1. 填写用户名与密码
2. 检查邮箱，填写验证码
# 安装steam Android客户端
1. 打开[https://media.steampowered.com/apps/steam-android/steam-3.10.0.apk](https://media.steampowered.com/apps/steam-android/steam-3.10.0.apk)并下载安装包（.apk）
2. 点击并安装即可
# 安装steam iOS客户端
1. 打开[https://apps.apple.com/us/app/steam-mobile/id495369748](https://apps.apple.com/us/app/steam-mobile/id495369748)，跳转到app store
2. 点击「获取」并安装即可
# 更改个人资料名称
如果你嫌初始名称不好听，可通过以下方法更改（此方法无法更改登录名称）
1. 点击客户端主页右上角的「管理账户」按钮（从左往右数第三个按钮）
2. 点击查看我的个人资料
3. 点击右侧的「编辑个人资料」
4. 更改个人资料名称
